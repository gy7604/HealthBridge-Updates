# HealthBridge 앱 업데이트 배포

이 저장소는 승인된 HealthBridge 앱 업데이트 파일을 제공하기 위한 배포 전용 공간입니다.

**현재 공개 버전: [0.2.1 / code7](https://github.com/gy7604/HealthBridge-Updates/releases/tag/v0.2.1)** (2026-11-09 사용자 승인). [APK 다운로드](https://github.com/gy7604/HealthBridge-Updates/releases/download/v0.2.1/HealthBridge-0.2.1.apk) · [업데이트 목록](https://raw.githubusercontent.com/gy7604/HealthBridge-Updates/main/latest.json)

이전 [0.2.0 / code6](https://github.com/gy7604/HealthBridge-Updates/releases/tag/v0.2.0)과 [0.1.4 / code5](https://github.com/gy7604/HealthBridge-Updates/releases/tag/v0.1.4) 릴리스는 그대로 보관합니다.

소유자의 정확한 버전별 승인 요청만 처리하는 게시 기능을 활성화했습니다. 이후 버전도 사용자 승인 후에만 공개합니다. 0.2.1 승인형 게시 실행 [42537457647](https://github.com/gy7604/HealthBridge-Updates/actions/runs/42537457647)이 성공했으며, APK 크기·SHA-256·원래 서명 인증서·latest.json이 일치합니다. 0.2.1은 앱 화면 상단의 큰 이름·소개 문구를 삭제하고, 버전을 맨 아래로 옮기며, 하단 네비게이션 버튼 겹침을 개선합니다. **실제 기기에서의 화면/업데이트/건강 기록 보존과 별도의 익명 직접 다운로드 시험은 아직 미검증입니다.**

앱 소스·건강정보·사용 기록·백업·키·비밀번호·토큰은 이 저장소에 보관하지 않습니다. 기존 HealthBridge 비공개 저장소·서버·DB·PC 빌더는 그대로 유지합니다.

빌드는 요청형 GitHub Actions가 기본이며 PC는 사용자가 선택할 때만 사용합니다. 이 저장소에서는 앱을 빌드하거나 설치하지 않습니다. push·PR·예약으로 반복 빌드하는 설정은 추가하지 않습니다.
