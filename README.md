소유자의 정확한 버전별 승인 요청만 처리하는 게시 기능을 활성화했습니다. 이후 버전도 사용자 승인 후에만 공개합니다. 0.2.0 승인형 게시 실행 [42531182124](https://github.com/gy7604/HealthBridge-Updates/actions/runs/42531182124)이 성공했으며, 릴리스 자산 크기·SHA-256·기존 서명 인증서와 latest.json의 값이 일치합니다. 0.2.0의 **익명 환경 실제 다운로드**, 휴대전화 설치·앱 내 업데이트, 실제 건강정보 공급자 연동은 아직 별도 미검증입니다.

앱 소스·건강정보·사용 기록·백업·키·비밀번호·토큰은 이 저장소에 보관하지 않습니다. 기존 HealthBridge 비공개 저장소·서버·DB·PC 빌더는 그대로 유지합니다.

빌드는 요청형 GitHub Actions가 기본이며 PC는 사용자가 선택할 때만 사용합니다. 이 저장소에서는 앱을 빌드하거나 설치하지 않습니다. push·PR·예약으로 반복 빌드하는 설정은 추가하지 않습니다.
